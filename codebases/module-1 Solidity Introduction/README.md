## Part One: Data Types

This part covers the Solidity data types introduced in the lesson: booleans, unsigned integers (`uint`), signed integers (`int`), fixed-size bytes, strings, and `enum` values. The goal is to understand how each type is declared, stored, and read back through public getters.

## Part Two: Functions

This part covers Solidity functions, including constructors, external functions, return values, `view`, `pure`, overloading, and console logging during testing. The practice shows how functions receive arguments, update state, and return values from expressions.
