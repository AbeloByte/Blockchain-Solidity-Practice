## Overview

This module moves from basic syntax into real interaction patterns between accounts
and contracts. The exercises cover calls, payable behavior, and safer control rules.

## Learning Focus

- Understand direct and low-level calls between contracts
- Handle fallback and receive flows in practical scenarios
- Apply revert patterns for authorization and invalid states
- Use owner-based restrictions and modifiers safely
- Manage Ether transfer flows across multiple contract actions
